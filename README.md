# Rosewater Radio — Project 015

A premium bridal-brunch editorial experience built with React, Vite and GSAP.

## Art direction
- Bridal Brunch / Editorial Celebration
- Rosewater blush, pistachio, pine and paper cream
- Radio-dial entry, editorial menu cards, Side A/Side B pacing, contact-hour image wall and sign-off finale
- 12 meaningful scenes with centralized customer-editable content in `src/data.js`
- Responsive layouts, priority hero loading and reduced-motion fallback

## Commands
```bash
npm install
npm run dev
npm run build
npm run qa:production
```

Production QA is defined in `qa/production-qa.mjs` and `.github/workflows/production-qa.yml` and targets the Git-linked Vercel project `tasksk015`.
